# Neighborly

**Help nearby. Feel good.**

A polished community mutual-aid web app focused on:

- **Food sharing** – excess meals, produce, pantry items
- **Tool lending** – drills, ladders, kitchen gear
- **Volunteer matching** – time, skills, helping hands
- **Item donations** – clothes, books, furniture
- **Requests** – ask for what you need
- **Impact tracking** – see the good your neighborhood creates

## Features

- Clean Apple-inspired design (light + dark mode)
- Quick actions to post food, tools, volunteer time, or donations
- Nearby listings and opportunities
- Explore with filters and search
- Bottom sheet forms and detail views
- Soft UI sounds
- Fully client-side (no backend needed)

## How to run

Just open `index.html` in any modern browser, or host it on GitHub Pages.

## Project structure

```
index.html      → Main HTML
app.js          → App logic
css/styles.css  → All styles
data.js         → Mock community listings
sounds.js       → UI sound effects
```

## GitHub Pages

After uploading to a new repository, go to **Settings → Pages**, choose the `main` branch and root folder, then save. Your app will be live at:

`https://YOUR-USERNAME.github.io/REPO-NAME/`
